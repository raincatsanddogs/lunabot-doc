图片处理服务 (imgtool)

提供类似 Linux 管道（Pipeline）的高性能图像处理系统。支持通过 /img 指令任意链式组合多种几何变换、色彩调整、动图帧编辑与合成特效，并附带二维码生成识别、群友语录排版、Markdown 渲染与取色工具。

图像处理​

使用方法​

[引用图片] /img <操作1> [参数1] <操作2> [参数2] ...

通过链式调用，前一个操作的输出结果会自动作为下一个操作的输入。支持同时回复单张图、多张图或合并转发折叠消息。

常用操作示例对应说明
[引用图片] /img rotate 90逆时针旋转图像 90 度
[引用图片] /img rotate 90 resize 0.5x链式执行：先旋转 90 度，再等比缩放到 50%
[引用多图] /img concat将多张图片按顺序垂直拼接为一张长图
[引用图片] /img check查看图像分辨率、格式、帧数与通道信息（别名：/img info）

内存图片队列管理​

[引用图片] /img push / /img pop / /img clear / /img rev

对于复杂的多图合成任务，可以先将图片临时存入列表并调整顺序。

常用操作示例对应说明
[引用图片] /img push将图片加入当前列表
/img pop移除列表中最新一张图片
/img clear清空图片暂存队列
/img rev反转队列中图片的先后顺序（别名：/imgrev）

常用参数一览表​

  • 几何与布局变换
  • 色彩与风格滤镜
  • 动图与帧处理
  • 高级与特效合成
参数名称调用语法说明与示例
旋转rotate <角度>逆时针旋转图像。例：rotate 90、rotate 180
镜像mirror [h/v]翻转图像，默认水平镜像。垂直翻转使用 mirror v
缩放resize <宽高或倍率>等比或绝对缩放。例：resize 0.5x、resize 500 500
裁剪crop <x> <y> <w> <h>截取矩形区域。例：crop 0 0 200 200
对称mid <方向>制作镜像对称。例：mid l (左对称)、mid r (右对称)
平铺repeat <列数> <行数>重复平铺排版。例：repeat 2 3
多图拼接concat [h/v]拼接列表中的图片。例：concat (垂直)、concat h (水平)
参数名称调用语法说明与示例
灰度化gray转换为黑白灰度图
色彩反转invert底片负片反色效果
亮度调节brighten <系数>调节亮度，1.0 为原始。例：brighten 1.5
对比度contrast <系数>强化或减弱对比。例：contrast 1.3
饱和度saturate <系数>调整色彩艳丽度。例：saturate 2.0
高斯模糊blur <半径>柔化/模糊处理。例：blur 5
锐化sharpen <系数>强化轮廓边缘细节。例：sharpen 2.0
参数名称调用语法说明与示例
格式转码gif / png转换为动画 GIF 或静态 PNG
倒放动图back将动图帧顺序完全逆转
调速倍速speed <倍率>加速或减速。例：speed 2.0 (2倍速)
帧提取extract <帧号或范围>提取指定帧画面。例：extract 0、extract 0-5
多帧合成stack <帧间隔毫秒>将队列中的多图压制为动图。例：stack 100
水流波动flow / fan将静图生成液体流动或风车旋转循环动图
参数名称调用语法说明与示例
智能抠图cutout基于深度学习去除主体背景，保留透明通道
裁剪透明shrink自动裁剪移除四周多余的纯透明边距
填充背景bg <颜色代码>为透明图填充底色。例：bg #ffffff、bg black
幻影坦克mirage合成在白底与黑底下呈现不同画面的半透明图
还原坦克demirage剥离还原幻影坦克两张原始底图

独立视觉实用工具​

二维码识别与生成(暂不可用)​

[引用图片] /scan（别名：/识别、/扫描） / /qrcode <文本或链接>（别名：/二维码）

自动解析图片中的二维码内容，或将指定文本/链接编码生成清晰的二维码图片。

常用操作示例对应说明
[引用图片] /scan识别所回复图片中的二维码内容并提取文本或链接
[引用图片] /识别使用中文别名识别图片中的二维码
/qrcode https://example.com将指定网页链接生成二维码图片
/二维码 欢迎访问使用中文别名将文本生成二维码图片

群友语录排版生成​

[引用回复] /语录（别名：/quote、/saying）

自动抓取被回复者的头像与昵称生成经典黑底名言语录海报。

常用操作示例对应说明
[引用消息] /语录自动抓取被回复者的头像与昵称生成经典语录海报
[引用消息] /quote使用英文别名生成语录海报
[引用消息] /saying使用通用别名生成语录海报

文本 Markdown 转图片渲染​

[引用消息] /md

在本地 Chromium 环境中将复杂 Markdown / HTML 渲染为图片并发送至群内。

常用操作示例对应说明
[引用消息] /md将 Markdown 文本渲染为排版长图发送

颜色展示与吸管取色​

/color <HEX代码或颜色名> / [引用图片] /pick <x> <y>

展示指定色值的色块卡片与 RGB/HSL 参数，或提取图片指定像素坐标处的色值。

常用操作示例对应说明
/color #ccaa88查看指定 HEX 颜色代码的色卡与参数详情
/color navy查看预设英文颜色名的色卡
[引用图片] /pick 100 200提取图片坐标 (100, 200) 处的像素颜色
