# 画廊服务 (gallery)

群聊公共图片收集系统。支持群员向主题画廊投递图片、图片哈希去重、随机展示以及图片包打包下载。

---

## 画廊浏览与抽取 {#browse}

### 抽取画廊图片 {#pick}
`/看 <画廊名或PID> [数量]`（别名：`/gall pick`）

随机从指定主题画廊抽取一张或多张图片，也可以通过图片编号 (PID) 查看指定图。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/看 猫咪` | 从“猫咪”画廊中随机抽选 1 张图片查看 |
| `/看 猫咪 x3` | 连续抽取展示 3 张不重复图片 |
| `/看 猫咪 -1` | 查看该画廊最新加入的倒数第 1 张图片 |
| `/看猫咪x5` | 连续抽取展示 5 张不重复图片（最多五张，参数之间可以不加空格） |
| `/看 1024` | 按全局 PID 精确调取编号为 1024 的图片 |
| `/看 1024 1025` | 同时查看指定的多张 PID 图片 |

---

### 查看画廊与图片列表 {#list}
`/看所有 [画廊名]`（别名：`/看全部`、`/gall list`）

列出当前所有开放的画廊清单及其图片数量，或者查询指定画廊内部收录的全部图片 PID 索引。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/看所有` | 列出当前已开放的全部主题画廊名称与收录图片数量 |
| `/看所有 猫咪` | 列出“猫咪”画廊内包含的所有图片 PID 清单 |
| `/gall list` | 使用英文别名列出所有画廊 |
| `/gall list 猫咪` | 使用英文别名查看指定画廊内的图片索引 |

---

### 获取画廊下载链接 {#download-link}
`/下载图包`（别名：`/下载看`、`/下载画廊`、`/gall download link`）

生成包含当前群内开放画廊的高速网页下载链接，群友可在浏览器端批量下载或打包归档。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/下载图包` | 生成当前群内全部画廊的高速打包下载网页链接 |

---

## 图片上传与投递 {#upload}

### 上传图片至画廊 {#add}
`[引用回复] /上传 <画廊名> [force]`（别名：`/添加`、`/gall add`、`/gall upload`）

向目标画廊投递新图片。系统默认执行哈希去重，防止重复图片入库。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `[引用图片] /上传 柴犬` | 将所回复的图片归档到“柴犬”画廊 |
| `[引用合并转发] /上传 柴犬` | 批量提取折叠转发消息内的全部图片入库 |
| `[引用图片] /上传 柴犬 force` | 强制上传，忽略相似度查重警告 |

---

### 撤回与记录查询 {#revert}
`/撤销上传`（别名：`/取消上传`、`/回退上传`、`/gall cancel`、`/gall revert`） / `/上传记录 <上传ID>`（别名：`/gall record`）

在误操作时快速撤回自己最近一次上传的图片，或查询特定批次的上传记录。超级管理员支持在撤销指令后指定上传 ID。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/撤销上传` | 撤回自己最近一次上传的图片 |
| 🛠️ `/撤销上传 123` | 撤回指定上传 ID 的图片（限超级管理员） |
| `/上传记录 123` | 查询指定批次上传的提交者与时间戳 |

## 画廊管理与运维 {#admin}

:::info 权限说明
本节指令仅限超级管理员 (SUPERUSER) 使用。
:::

### 画廊生命周期与权限控制 {#lifecycle}
🛠️ `/gall open <画廊名>` / 🛠️ `/gall close <画廊名>` / 🛠️ `/gall mode <画廊名> [edit|view|off]`

新建、归档主题画廊或调整访问模式（`edit` 允许自由上传、`view` 只读、`off` 完全隐藏）。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/gall open 柴犬` | 新建名为“柴犬”的主题画廊 |
| `/gall close 柴犬` | 归档下架指定画廊 |
| `/gall mode 柴犬` | 查看指定画廊当前的开放模式 |
| `/gall mode 柴犬 view` | 将画廊设为只读模式（禁止新上传） |
| `/gall cover 柴犬 1024` | 将 1024 号图片设为该画廊封面 |
| `/gall alias add 柴犬 dog` | 为画廊配置别名（别名：`/gall add alias`） |
| `/gall alias del 柴犬 dog` | 删除画廊配置的别名（别名：`/gall alias remove`） |

---

### 图片修订与维护 {#image-maintenance}
🛠️ `/gall del <PID或区间>` / 🛠️ `[引用图片] /gall replace <PID> [force]` / 🛠️ `/gall check <画廊名|all> [rehash]`

批量删除失效图片、替换高清图源、排查画廊重复图或从后台导出图包。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/gall del 100-120` | 按 PID 区间批量删除违规或失效图片（别名：`/gall remove`） |
| `[引用图片] /gall replace 1024` | 用回复的图片替换指定 PID 的图源 |
| `[引用图片] /gall replace 1024 force` | 替换图片并跳过查重检测 |
| `/gall check 柴犬` | 对指定画廊执行全量相似度查重排查 |
| `/gall check 柴犬 rehash` | 重新计算指定画廊内图片的哈希值并进行查重 |
| `/gall check all` | 对系统内所有画廊进行跨库查重 |
| `/gall reload 柴犬` | 手动向本地目录拷贝文件后同步重载数据库（别名：`/gall update`） |
| `/gall log 1024` | 查询指定 PID 图片的上传来源日志与操作人 |
| `/gall download 柴犬` | 从后台直接导出生成单个画廊的打包压缩文件 |
