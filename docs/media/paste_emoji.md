# 贴表情服务 (paste_emoji)

为 QQ 群消息添加表情回应，支持手动回复贴表情与群内趣味自动贴表情（自助餐模式）。  

■■■回复了你的消息：■

:::info 适配器要求
本功能依赖 OneBot / NapCat / LLOneBot 提供的 `set_msg_emoji_like` 底层接口。仅支持群聊环境。
:::

---

## 手动贴表情回应 {#paste-face}

### 贴表情 {#send-emoji}
`[引用回复] /贴表情 <表情内容或ID>`（别名：`/paste_face`、`/paste-face`）

为目标消息点赞或贴上指定表情回应。回复某条消息发送时贴到被回复的消息；直接发送时贴到当前指令消息。参数支持 Emoji 字符、十进制表情代码或十六进制码点。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/贴表情 👍` | 给当前指令消息贴上点赞表情回应 |
| `[引用消息] /贴表情 14` | 为被回复的群消息贴上 14 号系统表情 |
| `[引用消息] /paste_face 👍` | 使用英文别名贴表情 |

## 趣味自动贴表情（自助餐模式） {#auto-buffet}

为指定成员开启后，该成员后续发送的所有发言均会被 Bot 自动盖上表情印章。名单保存在内存中，重启后自动重置。

### 开启自动贴表情 {#start-buffet}
`/自㊗️餐 [@成员]`（别名：`/自㊗餐`）

为自己或群友开启自动贴表情。为他人开启需群管理员（🔧）或超级管理员（🛠️）权限。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/自㊗️餐` | 为自己开启自动贴表情模式 |
| 🔧 `/自㊗️餐 @群友` | 为指定群友开启自动贴表情（限群管理员） |
| `/自㊗餐` | 使用别名开启 |

---

### 停止自动贴表情 {#stop-buffet}
`/停止自㊗️餐 [@成员]`（别名：`/结束自㊗️餐`、`/关闭自㊗️餐`）

停止后续发言的自动贴表情处理。为他人关闭需群管理员（🔧）或超级管理员（🛠️）权限。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/停止自㊗️餐` | 退出本人的自动贴表情模式 |
| 🔧 `/结束自㊗️餐 @群友` | 为指定群成员关闭自动贴表情（限群管理员） |

---

## 服务状态与开关 {#status}

### 查询与切换服务开关 {#manage-status}
`/paste_emoji status` / 🛠️ `/paste_emoji <on|off>`

查看当前群内贴表情服务开启状态，或由超级管理员切换服务开关。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/paste_emoji status` | 查看当前群内贴表情服务是否开启 |
| 🛠️ `/paste_emoji on` | 在当前群开启贴表情服务（限超管） |
| 🛠️ `/paste_emoji off` | 在当前群关闭贴表情服务（限超管） |
