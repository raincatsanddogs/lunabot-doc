世界计划服务 (sekai)

世界计划（Project SEKAI）公开数据查询与群聊音游互动服务。主要提供跨区服的公开卡牌、乐曲定数、谱面走线、活动档案查询，以及 Q 版表情包生成和音游猜题互动小游戏。

提示

本服务专注于公开数据检索与群聊娱乐玩法。如果需要查看个人游戏账号信息、查询个人养成进度、查看打歌挖矿进度或使用组卡推荐，请使用 Haruki服务 (haruki)。

多区服切换与指令格式​

支持多服务器的查询指令，只需在指令斜杠后添加区服代码即可快速切换对应服务器的数据源：

  • 日服 (jp)
  • 国服 (cn)
  • 国际服 (en)
  • 台服 (tw)
  • 韩服 (kr)
  • 指令前缀：jp 或直接发送指令（日服为默认服）
  • 示例：/查卡、/查曲、/谱面、/活动
  • 特点：MasterData 更新最快，覆盖全部已实装及未来拆包乐曲与卡池。
  • 指令前缀：cn
  • 示例：/cn查卡、/cn查曲、/cn活动
  • 特点：支持国服独立进度、简中译名搜索与国服专属活动档案。
  • 指令前缀：en
  • 示例：/en查卡、/en查曲、/en活动
  • 特点：支持 Global 英文曲名检索。
  • 指令前缀：tw
  • 示例：/tw查卡、/tw查曲、/tw活动
  • 特点：支持繁体中文服数据检索。
  • 指令前缀：kr
  • 示例：/kr查卡、/kr查曲、/kr活动
  • 特点：覆盖韩服数据。

卡牌与卡池查询​

查卡与高清卡面​

/[区服]查卡 [筛选条件/卡牌ID/角色-序号]（别名：/卡牌、/card）

多维度检索全服公开卡牌数据。支持按组合、角色、属性、稀有度、限定类型复合筛选。

常用操作示例对应说明
/查卡 123查询 ID 为 123 的卡牌详细面板与技能数值
/查卡 miku-1查询初音未来倒数第 1 张（最新发布）卡牌
/查卡 mmj cool 限定筛选 MMJ 团的蓝星限定卡牌
/查卡 mnr 2025年 生日筛选花里实乃理 2025 年生日卡
/[区服]卡面 <卡牌ID或角色序号>获取指定卡牌花前与花后的超清原画大图

角色别名查询​

/[区服]角色别名 <角色名/常用昵称>（别名：/查角色别名、/pjsk chara alias）

查询世界计划登场角色的全量官方与玩家常用昵称及对应角色 ID。支持使用官方译名、英文或已收录的常用别名进行反查。

常用操作示例对应说明
/角色别名 miku查询初音未来已收录的所有中英文别名与常用昵称
/角色别名 虾支持通过已有常用昵称反查对应角色及全量别名
/角色别名 实乃理查询花里实乃理的全部群聊常用称呼

卡池信息查询​

/[区服]卡池 [ID|年份|复刻|当前|leak]（别名：/卡池列表）

浏览正在开放的卡池或检索历史/未来拆包卡池排期。

常用操作示例对应说明
/卡池查看当前全服正在开放的招募卡池
/卡池 123按 ID 查询指定卡池概率与包含卡牌
/卡池 2025年 复刻检索 2025 年的复刻卡池排期
/卡池 leak查看未来即将实装的拆包卡池预测

乐曲与谱面查询​

查曲与官方曲绘​

/[区服]查曲 <歌曲ID或曲名>（别名：/pjsk music、/song）

查询歌曲的基本信息、作词曲名义、各难度 Note 物量、歌曲时长与出处。

常用操作示例对应说明
/查曲 id123按歌曲 ID 查询曲目详情
/查曲 六兆年按歌名或常用别名查询曲目
/查曲 mnr1查询实乃理一箱活动曲
/[区服]查曲绘 <曲名或ID>获取歌曲官方原画曲绘封面大图
/[区服]查BPM <歌曲>查看歌曲初始 BPM、主节奏及变速区间
/[区服]查物量 <数值>查询 Note 总数等于指定数量的歌曲

谱面预览与定数列表​

/[区服]谱面 <歌曲> [难度] [refresh]（别名：/谱面预览）

渲染歌曲对应难度的完整轨道谱面走线长图（默认 MASTER 难度）。

常用操作示例对应说明
/谱面 虾预览指定歌曲 MASTER 难度的谱面走向
/谱面 id123 expert预览指定歌曲 EXPERT 难度的谱面
/[区服]歌曲列表 [难度] [等级范围/定数]按定数表展示全部歌曲清单（如 /歌曲列表 master 31 34）

歌曲排行与效率看板​

/[区服]歌曲排行 [单人|多人|auto] [比较依据] [筛选条件]（别名：/歌曲比较、/歌曲排名、/music board、/pjsk music board）

查询全曲库在不同打歌模式下的效率看板与得分排行。支持按 Live 分数、时间效率（pt/h）、火效率（pt/火）或每秒按键物量（tps）进行排行对比，支持指定技能组、综合力及活动加成。支持日服数据源。

常用操作示例对应说明
/歌曲排行查询单人（挑战）Live 默认技能组下的全曲目得分排行榜
/歌曲排行 多人 pt/h查询多人模式下时间效率最高（最适宜冲榜刷分）的歌曲排行
/歌曲排行 expert >=28筛选 EXPERT 难度 28 级及以上的单曲效率榜
/歌曲排行 虾ex 龙ma重点对比指定曲目不同难度的得分效率（别名：/music board）

歌曲别名管理​

/歌曲别名 <歌曲ID> / /添加歌曲别名 <歌曲ID> <别名1,别名2>（别名：/pjsk alias add）

查询或为曲目提交新增群聊常用别名。删除特定别名限超级管理员操作。

常用操作示例对应说明
/歌曲别名 123查询该曲目已收录的所有群聊常用别名
/添加歌曲别名 630 knd6,奏6为歌曲追加新别名（别名：/pjsk alias add）
🛠️ /删除歌曲别名 <别名>删除特定别名词条（限超级管理员，别名：/pjsk alias del）

活动与剧情查询​

活动信息查询​

/[区服]活动 [ID|-1|箱活缩写|团名]（别名：/pjsk event）

查询当期或往期活动的周期、类型（普活/5v5/WL）、Bonus 属性与加成角色。

常用操作示例对应说明
/活动查看当前正在进行的活动情报
/活动 -1查看上一期（倒数第一期）活动详情
/[区服]活动列表 [年份/团名/属性]批量筛选活动清单（如 /活动列表 25h 蓝星 2025年）

AI剧情与故事总结​

/[区服]活动剧情 [活动ID/缩写] [refresh] / /[区服]卡面剧情 <卡牌ID/角色序号> [refresh]（别名：/活动故事、/卡牌剧情）

利用大语言模型（LLM）对活动剧情或卡牌一二节剧情进行智能提炼与排版长图渲染。附带 refresh 参数可强制向 AI 引擎重新请求生成最新总结。支持日服数据源。

常用操作示例对应说明
/活动剧情查看当前正在进行的活动剧情 AI 总结长图
/活动剧情 mnr1按活动缩写查询指定活动（如实乃理一箱）的故事总结
/活动剧情 123 refresh强制重新生成并刷新 ID 为 123 的活动剧情总结
/卡面剧情 123查询 ID 为 123 的卡牌前篇与后篇专属剧情 AI 总结
/卡面剧情 miku-1查询指定角色最新卡牌的卡面故事总结（别名：/卡牌剧情）

虚拟Live演出排期​

/[区服]虚拟Live（别名：/虚拟live、/vlive、/pjsk live）

查询游戏内正在进行中或近 7 天内即将开演的虚拟演出（Virtual Live）排期场次。包含活动结束后演出（After-Live）、角色生日与纪念日 Live 的演出时刻表、出场角色与参演报酬奖励。

常用操作示例对应说明
/虚拟Live查看当前区服近期全部虚拟 Live 场次排期与奖励列表
/cn虚拟Live切换查询国服近期虚拟演出场次信息
/vlive快捷别名查询虚拟 Live 场次

PJSK表情包制作​

表情生成与文字印制​

/[区服]pjsk表情 <角色名或表情ID> [自定义文本] [png]（别名：/pjsk stamp）

使用游戏内置的萌系 Q 版表情素材制作表情包。

常用操作示例对应说明
/pjsk表情 miku浏览初音未来的全部表情底图与编号清单
/pjsk表情 123提取 ID 为 123 的透明底表情原图
/pjsk表情 123 请多关照！将文字合成到 123 号表情上并发送
/pjsk表情 123 png获取 ID 为 123 的表情透明底 png 图片
/pjsk随机表情 [角色名] [自定义文字]随机挑选表情底图并印上文字

表情底图维护​

/pjsk表情底图 <ID> / /pjsk表情刷新 <ID>

查看或重新刷新指定表情的透明底图素材。

常用操作示例对应说明
/pjsk表情底图 123查看特定表情的透明底图素材
/pjsk表情刷新 123重新请求 AI 抠图引擎更新底图

音游竞猜与趣味娱乐​

群内竞猜小游戏​

/[区服]猜曲绘 [难度] / /[区服]猜谱面 [难度]

在群内发起音游知识竞猜互动，答对自动积分。发送“提示”可获得线索，发送“结束猜”可提前退出。

常用操作示例对应说明
/猜曲绘根据局部的马赛克或裁剪原画猜曲名
/猜谱面 expert根据局部的 Note 走线截图猜歌曲
/猜卡面根据局部衣物、发饰或眼部特征猜卡牌归属
/听歌识曲播放 1 至 3 秒短音频片段猜歌曲

模拟抽卡体验​

/单抽 / /十连 [卡池ID] / /200连 -1

以官方概率模拟卡池抽卡与抽井体验。

常用操作示例对应说明
/十连在当期卡池中模拟一次十连抽卡
/200连 -1在上一期卡池中模拟 200 连抽卡
/pec查看本群今日娱乐功能调用次数
🔧 /pel <数量>设置本群每日娱乐指令调用次数上限（限管理员）

公共数据与工具​

公共数据与服务通知​

/角色生日 / /pjsk注册

提供游戏公共数据查询及群内开服/活动通知开关。

常用操作示例对应说明
/角色生日查询最近即将过生日/纪念日的角色信息与纪念 Live 时间
/pjsk注册一键生成日服/国际服的新人引继游客账号
🛠️ /pjsk update立刻同步官方各区服最新的 MasterData 数据库（限超管）
🛠️ /pjsk开启 live开启本群虚拟 Live 定时提醒（限超级管理员）
🛠️ /pjsk关闭 update关闭本群游戏更新推送（限超级管理员）
