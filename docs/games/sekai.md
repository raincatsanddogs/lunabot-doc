# 世界计划剧情与娱乐 (sekai)

世界计划（Project SEKAI）AI 剧情故事总结与群聊音游互动服务。主要提供基于大语言模型（LLM）的活动与卡面剧情提炼、Q 版表情包生成、音游猜题互动小游戏与模拟抽卡体验。

:::info 提示
本服务专注于 AI 剧情提炼与群聊娱乐玩法。如果需要查询卡牌、曲目定数、谱面走线、活动与榜线数据、个人账号进度或使用组卡推荐，请使用 **[Haruki服务 (haruki)](/docs/games/haruki)**。
:::

## AI剧情与故事总结 {#story-summary}

`/[区服]活动剧情 [活动ID/缩写] [refresh]` / `/[区服]卡面剧情 <卡牌ID/角色序号> [refresh]`（别名：`/活动故事`、`/卡牌剧情`）

利用大语言模型（LLM）对活动剧情或卡牌一二节剧情进行智能提炼与排版长图渲染。附带 `refresh` 参数可强制向 AI 引擎重新请求生成最新总结。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/活动剧情` | 查看当前正在进行的活动剧情 AI 总结长图 |
| `/活动剧情 mnr1` | 按活动缩写查询指定活动（如实乃理一箱）的故事总结 |
| `/活动剧情 123 refresh` | 强制重新生成并刷新 ID 为 123 的活动剧情总结 |
| `/卡面剧情 123` | 查询 ID 为 123 的卡牌前篇与后篇专属剧情 AI 总结 |
| `/卡面剧情 miku-1` | 查询指定角色最新卡牌的卡面故事总结（别名：`/卡牌剧情`） |

## PJSK表情包制作 {#stamps}

### 表情生成与文字印制 {#stamp-generate}
`/[区服]pjsk表情 <角色名或表情ID> [自定义文本] [png]`（别名：`/pjsk stamp`）

使用游戏内置的萌系 Q 版表情素材制作表情包。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/pjsk表情 miku` | 浏览初音未来的全部表情底图与编号清单 |
| `/pjsk表情 123` | 提取 ID 为 123 的透明底表情原图 |
| `/pjsk表情 123 请多关照！` | 将文字合成到 123 号表情上并发送 |
| `/pjsk表情 123 png` | 获取 ID 为 123 的表情透明底 png 图片 |
| `/pjsk随机表情 [角色名] [自定义文字]` | 随机挑选表情底图并印上文字 |

---

### 表情底图维护 {#stamp-management}
`/pjsk表情底图 <ID>` / `/pjsk表情刷新 <ID>`

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/pjsk表情底图 123` | 查看特定表情的透明底图素材 |
| `/pjsk表情刷新 123` | 重新请求 AI 抠图引擎更新底图 |

## 音游竞猜与趣味娱乐 {#entertainment}

### 群内竞猜小游戏 {#guess-games}
`/[区服]猜曲绘 [难度]` / `/[区服]猜谱面 [难度]`

在群内发起音游知识竞猜互动，答对自动积分。发送“`提示`”可获得线索，发送“`结束猜`”可提前退出。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/猜曲绘` | 根据局部的马赛克或裁剪原画猜曲名 |
| `/猜谱面 expert` | 根据局部的 Note 走线截图猜歌曲 |
| `/猜卡面` | 根据局部衣物、发饰或眼部特征猜卡牌归属 |
| `/听歌识曲` | 播放 1 至 3 秒短音频片段猜歌曲 |

### 模拟抽卡体验 {#mock-gacha}
`/单抽` / `/十连 [卡池ID]` / `/200连 -1`

以官方概率模拟卡池抽卡与抽井体验。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/十连` | 在当期卡池中模拟一次十连抽卡 |
| `/200连 -1` | 在上一期卡池中模拟 200 连抽卡 |
| `/pec` | 查看本群今日娱乐功能调用次数 |
| 🔧 `/pel <数量>` | 设置本群每日娱乐指令调用次数上限（限管理员） |

## 数据维护与服务通知 {#admin}

### 数据同步与推送订阅 {#pjsk-tools}

提供游戏公共数据同步及群内开服/活动通知开关。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| 🛠️ `/pjsk update` | 立刻同步官方各区服最新的 MasterData 数据库（限超管） |
| 🛠️ `/pjsk开启 live` | 开启本群虚拟 Live 定时提醒（限超级管理员） |
| 🛠️ `/pjsk关闭 update` | 关闭本群游戏更新推送（限超级管理员） |
