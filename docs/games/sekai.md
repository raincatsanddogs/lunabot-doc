# 世界计划服务 (sekai)

世界计划（Project SEKAI）公开数据查询与群聊音游互动服务。主要提供跨区服的公开卡牌、乐曲定数、谱面走线、活动档案查询，以及 Q 版表情包生成和音游猜题互动小游戏。

:::info 提示
本服务专注于公开数据检索与群聊娱乐玩法。如果需要查看个人游戏账号信息、查询个人养成进度、查看打歌挖矿进度或使用组卡推荐，请使用 **[Haruki服务 (haruki)](/docs/games/haruki)**。
:::

## 多区服切换与指令格式 {#multi-server}

支持多服务器的查询指令，**只需在指令斜杠后添加区服代码**即可快速切换对应服务器的数据源：

<Tabs>
<TabItem value="jp" label="日服 (jp)" default>

- **指令前缀**：`jp` 或直接发送指令（日服为默认服）
- **示例**：`/查卡`、`/查曲`、`/谱面`、`/活动`
- **特点**：MasterData 更新最快，覆盖全部已实装及未来拆包乐曲与卡池。

</TabItem>
<TabItem value="cn" label="国服 (cn)">

- **指令前缀**：`cn`

- **特点**：支持国服独立进度、简中译名搜索与国服专属活动档案。

<TabItem value="en" label="国际服 (en)">

## 卡牌与卡池查询 {#cards}

### 查卡与高清卡面 {#card-search}
`/[区服]查卡 [筛选条件/卡牌ID/角色-序号]`（别名：`/卡牌`、`/card`）

多维度检索全服公开卡牌数据。支持按组合、角色、属性、稀有度、限定类型复合筛选。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/查卡 123` | 查询 ID 为 123 的卡牌详细面板与技能数值 |
| `/查卡 miku-1` | 查询初音未来倒数第 1 张（最新发布）卡牌 |
| `/查卡 mmj cool 限定` | 筛选 MMJ 团的蓝星限定卡牌 |
| `/查卡 mnr 2025年 生日` | 筛选花里实乃理 2025 年生日卡 |
| `/[区服]卡面 <卡牌ID或角色序号>` | 获取指定卡牌花前与花后的超清原画大图 |

---

### 角色别名查询 {#chara-alias}
`/[区服]角色别名 <角色名/常用昵称>`（别名：`/查角色别名`、`/pjsk chara alias`）

查询世界计划登场角色的全量官方与玩家常用昵称及对应角色 ID。支持使用官方译名、英文或已收录的常用别名进行反查。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/角色别名 miku` | 查询初音未来已收录的所有中英文别名与常用昵称 |
| `/角色别名 虾` | 支持通过已有常用昵称反查对应角色及全量别名 |
| `/角色别名 实乃理` | 查询花里实乃理的全部群聊常用称呼 |

---

### 卡池信息查询 {#gacha}
`/[区服]卡池 [ID|年份|复刻|当前|leak]`（别名：`/卡池列表`）

浏览正在开放的卡池或检索历史/未来拆包卡池排期。

| 常用操作示例 | 对应说明 |
| :--- | :--- |

| `/卡池 123` | 按 ID 查询指定卡池概率与包含卡牌 |
| `/卡池 2025年 复刻` | 检索 2025 年的复刻卡池排期 |
| `/卡池 leak` | 查看未来即将实装的拆包卡池预测 |

## 乐曲与谱面查询 {#music}

### 查曲与官方曲绘 {#song-search}
`/[区服]查曲 <歌曲ID或曲名>`（别名：`/pjsk music`、`/song`）

查询歌曲的基本信息、作词曲名义、各难度 Note 物量、歌曲时长与出处。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/查曲 id123` | 按歌曲 ID 查询曲目详情 |
| `/查曲 六兆年` | 按歌名或常用别名查询曲目 |
| `/查曲 mnr1` | 查询实乃理一箱活动曲 |
| `/[区服]查曲绘 <曲名或ID>` | 获取歌曲官方原画曲绘封面大图 |
| `/[区服]查BPM <歌曲>` | 查看歌曲初始 BPM、主节奏及变速区间 |
| `/[区服]查物量 <数值>` | 查询 Note 总数等于指定数量的歌曲 |

---

### 谱面预览与定数列表 {#chart-preview}
`/[区服]谱面 <歌曲> [难度] [refresh]`（别名：`/谱面预览`）

渲染歌曲对应难度的完整轨道谱面走线长图（默认 MASTER 难度）。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/谱面 虾` | 预览指定歌曲 MASTER 难度的谱面走向 |
| `/谱面 id123 expert` | 预览指定歌曲 EXPERT 难度的谱面 |
| `/[区服]歌曲列表 [难度] [等级范围/定数]` | 按定数表展示全部歌曲清单（如 `/歌曲列表 master 31 34`） |

---

### 歌曲排行与效率看板 {#music-board}
`/[区服]歌曲排行 [单人|多人|auto] [比较依据] [筛选条件]`（别名：`/歌曲比较`、`/歌曲排名`、`/music board`、`/pjsk music board`）

查询全曲库在不同打歌模式下的效率看板与得分排行。支持按 Live 分数、时间效率（`pt/h`）、火效率（`pt/火`）或每秒按键物量（`tps`）进行排行对比，支持指定技能组、综合力及活动加成。支持日服数据源。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/歌曲排行` | 查询单人（挑战）Live 默认技能组下的全曲目得分排行榜 |
| `/歌曲排行 多人 pt/h` | 查询多人模式下时间效率最高（最适宜冲榜刷分）的歌曲排行 |
| `/歌曲排行 expert >=28` | 筛选 EXPERT 难度 28 级及以上的单曲效率榜 |
| `/歌曲排行 虾ex 龙ma` | 重点对比指定曲目不同难度的得分效率（别名：`/music board`） |

查询或为曲目提交新增群聊常用别名。删除特定别名限超级管理员操作。

| 常用操作示例 | 对应说明 |

| 🛠️ `/删除歌曲别名 <别名>` | 删除特定别名词条（限超级管理员，别名：`/pjsk alias del`） |

### AI剧情与故事总结 {#story-summary}
`/[区服]活动剧情 [活动ID/缩写] [refresh]` / `/[区服]卡面剧情 <卡牌ID/角色序号> [refresh]`（别名：`/活动故事`、`/卡牌剧情`）

利用大语言模型（LLM）对活动剧情或卡牌一二节剧情进行智能提炼与排版长图渲染。附带 `refresh` 参数可强制向 AI 引擎重新请求生成最新总结。支持日服数据源。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/活动剧情` | 查看当前正在进行的活动剧情 AI 总结长图 |
| `/活动剧情 mnr1` | 按活动缩写查询指定活动（如实乃理一箱）的故事总结 |
| `/活动剧情 123 refresh` | 强制重新生成并刷新 ID 为 123 的活动剧情总结 |
| `/卡面剧情 123` | 查询 ID 为 123 的卡牌前篇与后篇专属剧情 AI 总结 |
| `/卡面剧情 miku-1` | 查询指定角色最新卡牌的卡面故事总结（别名：`/卡牌剧情`） |

### 虚拟Live演出排期 {#vlive}
`/[区服]虚拟Live`（别名：`/虚拟live`、`/vlive`、`/pjsk live`）

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/虚拟Live` | 查看当前区服近期全部虚拟 Live 场次排期与奖励列表 |
| `/cn虚拟Live` | 切换查询国服近期虚拟演出场次信息 |
| `/vlive` | 快捷别名查询虚拟 Live 场次 |

## 音游竞猜与趣味娱乐 {#entertainment}

### 群内竞猜小游戏 {#guess-games}
`/[区服]猜曲绘 [难度]` / `/[区服]猜谱面 [难度]`

在群内发起音游知识竞猜互动，答对自动积分。发送“`提示`”可获得线索，发送“`结束猜`”可提前退出。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/猜曲绘` | 根据局部的马赛克或裁剪原画猜曲名 |
| `/猜谱面 expert` | 根据局部的 Note 走线截图猜歌曲 |
| `/猜卡面` | 根据局部衣物、发饰或眼部特征猜卡牌归属 |
| `/听歌识曲` | 播放 1 至 3 秒短音频片段猜歌曲 |
