# Haruki服务 (haruki)

基于 [HarukiBot NEO](https://neo.haruki.seiunx.com/) 与 [Haruki工具箱](https://haruki.seiunx.com/) 的 Project SEKAI 查询系统。覆盖全部区服的账号数据查询、名片生成、卡牌服装、定数与谱面走线、实时榜线追踪、智能组卡以及 MySekai 烤森资源分析。

:::tip 快捷单指令帮助
在任何指令后加上 `help`（例如 `/个人信息 help`、`/查卡 help`、`/sk help`）均可在群内获取该指令的最新详细图文用法。
:::

---

## 多区服支持与前缀切换 {#multi-server}

支持五大区服的指令，**只需在指令斜杠后添加对应的区服代码**即可切换目标服务器：

<Tabs>
<TabItem value="jp" label="日服 (jp)" default>

- **指令前缀**：`jp`（例如 `/个人信息`、`/jpsk`、`/jp查曲`）
- **特点**：不加前缀时默认查询日服。

</TabItem>
<TabItem value="cn" label="国服 (cn)">

- **指令前缀**：`cn`（例如 `/cn个人信息`、`/cn查卡`、`/cnsk`）
- **特点**：支持国服特有的活动排期、卡池进度、中文曲名匹配与国服专属档线。

</TabItem>
<TabItem value="tw" label="台服 (tw)">

- **指令前缀**：`tw`（例如 `/tw个人信息`、`/tw查卡`、`/twsk`）
- **特点**：支持繁体中文服（台港澳服）的数据检索与活动监控。

</TabItem>
<TabItem value="kr" label="韩服 (kr)">

- **指令前缀**：`kr`（例如 `/kr个人信息`、`/kr查曲`、`/krsk`）
- **特点**：覆盖韩服数据与活动追踪。

</TabItem>
<TabItem value="en" label="国际服 (en)">

- **指令前缀**：`en`（例如 `/en个人信息`、`/en查卡`、`/ensk`）
- **特点**：覆盖 Global 国际服数据，支持英文曲名与国际服卡池。

</TabItem>
</Tabs>

:::note 账号与数据前置说明
部分数据（如个人养成进度、拥有卡牌、打歌挖矿、组卡推荐等）必须在 [Haruki工具箱](https://haruki.seiunx.com/) 中绑定游戏账号并上传抓包数据（Suite / MySekai 数据）才可查询。
:::

## 个人资料与账号设置 {#account}

### 账号绑定与管理 {#bind}
`/[区服]绑定 <UID>`（别名：`/pjsk bind`、`/pjsk id`）

通过游戏 UID 绑定游戏账号。支持绑定多个账号，最新绑定的账号会自动设为当前区服主账号。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/绑定 114514` | 绑定日服游戏账号 |
| `/cn绑定 114514` | 绑定国服游戏账号 |
| `/绑定列表` | 查看自己在各区服已绑定的全部游戏账号与 UID |
| `/设置主账号 <序号或UID>` | 切换当前区服的默认主账号 |
| `/交换绑定 <序号1> <序号2>` | 调整多账号的排列顺序 |
| `/账号解绑 [序号/UID]` | 解除指定绑定的游戏账号 |

---

### 个人信息与名片 {#profile}
`/[区服]个人信息 [UID|用户]`（别名：`/个人中心`、`/profile`）

生成高精度的游戏个人信息看板（包含段位、等级、综合力、助战队伍与高难打歌成就）。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/个人信息` | 查看本人默认绑定的游戏名片 |
| `/cn个人信息` | 查看国服账号的个人名片 |
| `/个人信息 114514` | 查询指定游戏 UID 的名片 |
| `/自定义个人信息` | 生成包含个性化组件与排版的自定义名片 |
| `/查询注册时间` | 查询游戏账号的具体建号注册时间 |

---

### 隐私与名片定制 {#privacy-and-customization}
`/[区服]隐藏UID` / `/[区服]显示UID`

设置名片图片中是否隐藏公开 UID，或配置自定义个人信息背景。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/隐藏UID` | 在生成的名片图片中隐藏真实 UID |
| `/显示UID` | 在名片中恢复显示真实 UID |
| `/抓包状态查询` | 查询抓包数据在 Haruki 工具箱中的更新时间与有效性 |
| `/账号验证` | 根据引导在游戏内完成账号归属权验证 |
| `/自定义个人信息背景` | 上传自定义图片作为个人信息界面的底图 |

## 音乐与乐曲谱面 {#music}

### 查曲与定数表 {#song-search}
`/[区服]查曲 <歌曲ID|曲名|别名>`

查询歌曲的基础信息、各难度等级、物量分布、谱师与所属活动。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/查曲 112` | 按歌曲 ID 查询详情 |
| `/查曲 虾` | 通过常用歌曲别名查询 |
| `/[区服]难度排行` | 查看各难度的官方定数与难度排行图 |
| `/[区服]查曲绘 <歌曲>` | 获取歌曲官方曲绘封面大图 |
| `/[区服]查BPM <歌曲>` | 查看歌曲初始 BPM 与变速走势 |
| `/[区服]查物量 <数值>` | 查询物量等于该数值的歌曲 |

---

### 谱面预览与样式 {#chart-preview}
`/[区服]谱面预览 <歌曲ID|曲名> [难度]`

生成歌曲全曲谱面长图，直观预览轨道按键与走线细节（默认 MASTER 难度）。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/谱面预览 112 expert` | 预览指定歌曲 EXPERT 难度的谱面图 |
| `/谱面样式设置` | 自定义谱面预览图的按键配色与背景透明度 |
| `/乐曲逮捕` | 快速查询最近新实装的高难或话题乐曲 |

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/每日挑战` | 查询各角色每日挑战 Live 的达成等级与未领水晶 |
| `/挖矿` | 统计本人尚未拿满奖励的歌曲与可挖矿量总数 |
| `/打歌进度` | 生成 Clear / FC / AP 打歌成就汇总看板 |

`/[区服]角色加成` / `/[区服]羁绊`

查询角色间的牵绊等级、综合力加成百分比及区域道具升级情况。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/角色加成` | 查看各角色的综合力提升加成百分比 |
| `/羁绊` | 查询本人角色间的牵绊等级与经验进度 |
| `/区域道具` | 查看已升满与待升级的区域道具等级 |
| `/领队统计` | 统计各角色担任领队（队长）的累计演出次数 |
