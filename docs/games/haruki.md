# Haruki服务 (haruki)

基于 [HarukiBot NEO](https://neo.haruki.seiunx.com/) 与 [Haruki工具箱](https://haruki.seiunx.com/) 的 Project SEKAI 查询系统。覆盖全部区服的账号数据查询、名片生成、卡牌服装、定数与谱面走线、实时榜线追踪、智能组卡以及 MySekai 烤森资源分析。

:::tip 快捷单指令帮助
在任何指令后加上 `help`（例如 `/个人信息 help`、`/查卡 help`、`/sk help`）均可在群内获取该指令的最新详细图文用法。
:::

---

## 多区服支持与前缀切换 {#multi-server}

支持五大区服的指令，**只需在指令斜杠后添加对应的区服代码**即可切换目标服务器：

<Tabs>
<TabItem value="jp" label="日服 (jp)" default>

- **指令前缀**：`jp`（例如 `/个人信息`、`/sk`、`/查曲`）
- **特点**：不加前缀时默认查询日服。

</TabItem>
<TabItem value="cn" label="国服 (cn)">

- **指令前缀**：`cn`（例如 `/cn个人信息`、`/cn查卡`、`/cnsk`）
- **特点**：支持国服特有的活动排期、卡池进度、中文曲名匹配与国服专属档线。

</TabItem>
<TabItem value="tw" label="台服 (tw)">

- **指令前缀**：`tw`（例如 `/tw个人信息`、`/tw查卡`、`/twsk`）
- **特点**：支持繁体中文服（台港澳服）的数据检索与活动监控。

</TabItem>
<TabItem value="kr" label="韩服 (kr)">

- **指令前缀**：`kr`（例如 `/kr个人信息`、`/kr查曲`、`/krsk`）
- **特点**：覆盖韩服数据与活动追踪。

</TabItem>
<TabItem value="en" label="国际服 (en)">

- **指令前缀**：`en`（例如 `/en个人信息`、`/en查卡`、`/ensk`）
- **特点**：覆盖 Global 国际服数据，支持英文曲名与国际服卡池。

</TabItem>
</Tabs>

:::note 账号与数据前置说明
部分数据（如个人养成进度、拥有卡牌、打歌挖矿、组卡推荐等）必须在 [Haruki工具箱](https://haruki.seiunx.com/) 中绑定游戏账号并上传抓包数据（Suite / MySekai 数据）才可查询。
:::

## 个人资料与账号设置 {#account}

### 账号绑定与管理 {#bind}
`/[区服]绑定 <UID>`（别名：`/pjsk bind`、`/pjsk id`、`/pjsk 绑定`）

通过游戏 UID 绑定游戏账号。支持绑定多个账号，最新绑定的账号会自动设为当前区服主账号。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/绑定 114514` | 绑定日服游戏账号 |
| `/cn绑定 114514` | 绑定国服游戏账号 |
| `/绑定列表` | 查看自己在各区服已绑定的全部游戏账号与 UID（别名：`/pjsk bind list`） |
| `/设置主账号 <序号或UID>` | 切换当前区服的默认主账号（别名：`/设置默认绑定`、`/pjsk set main`） |
| `/清除默认绑定` | 清除当前区服的默认绑定账号（别名：`/取消默认绑定`、`/清除主账号`） |
| `/交换绑定 <序号1> <序号2>` | 调整多账号的排列顺序 |
| `/解绑 [序号/UID]` | 解除指定绑定的游戏账号（别名：`/取消绑定`、`/pjsk unbind`） |
