Haruki服务 (haruki)

基于 HarukiBot NEO 与 Haruki工具箱 的 Project SEKAI 查询系统。覆盖全部区服的账号数据查询、名片生成、卡牌服装、定数与谱面走线、实时榜线追踪、智能组卡以及 MySekai 烤森资源分析。

快捷单指令帮助

在任何指令后加上 help（例如 /个人信息 help、/查卡 help、/sk help）均可在群内获取该指令的最新详细图文用法。

多区服支持与前缀切换​

支持五大区服的指令，只需在指令斜杠后添加对应的区服代码即可切换目标服务器：

  • 日服 (jp)
  • 国服 (cn)
  • 台服 (tw)
  • 韩服 (kr)
  • 国际服 (en)
  • 指令前缀：jp（例如 /个人信息、/jpsk、/jp查曲）
  • 特点：不加前缀时默认查询日服。
  • 指令前缀：cn（例如 /cn个人信息、/cn查卡、/cnsk）
  • 特点：支持国服特有的活动排期、卡池进度、中文曲名匹配与国服专属档线。
  • 指令前缀：tw（例如 /tw个人信息、/tw查卡、/twsk）
  • 特点：支持繁体中文服（台港澳服）的数据检索与活动监控。
  • 指令前缀：kr（例如 /kr个人信息、/kr查曲、/krsk）
  • 特点：覆盖韩服数据与活动追踪。
  • 指令前缀：en（例如 /en个人信息、/en查卡、/ensk）
  • 特点：覆盖 Global 国际服数据，支持英文曲名与国际服卡池。
账号与数据前置说明

部分数据（如个人养成进度、拥有卡牌、打歌挖矿、组卡推荐等）必须在 Haruki工具箱 中绑定游戏账号并上传抓包数据（Suite / MySekai 数据）才可查询。

个人资料与账号设置​

账号绑定与管理​

/[区服]绑定 <UID>（别名：/pjsk bind、/pjsk id）

通过游戏 UID 绑定游戏账号。支持绑定多个账号，最新绑定的账号会自动设为当前区服主账号。

常用操作示例对应说明
/绑定 114514绑定日服游戏账号
/cn绑定 114514绑定国服游戏账号
/绑定列表查看自己在各区服已绑定的全部游戏账号与 UID
/设置主账号 <序号或UID>切换当前区服的默认主账号
/交换绑定 <序号1> <序号2>调整多账号的排列顺序
/账号解绑 [序号/UID]解除指定绑定的游戏账号

个人信息与名片​

/[区服]个人信息 [UID|用户]（别名：/个人中心、/profile）

生成高精度的游戏个人信息看板（包含段位、等级、综合力、助战队伍与高难打歌成就）。

常用操作示例对应说明
/个人信息查看本人默认绑定的游戏名片
/cn个人信息查看国服账号的个人名片
/个人信息 114514查询指定游戏 UID 的名片
/自定义个人信息生成包含个性化组件与排版的自定义名片
/查询注册时间查询游戏账号的具体建号注册时间

隐私与名片定制​

/[区服]隐藏UID / /[区服]显示UID

设置名片图片中是否隐藏公开 UID，或配置自定义个人信息背景。

常用操作示例对应说明
/隐藏UID在生成的名片图片中隐藏真实 UID
/显示UID在名片中恢复显示真实 UID
/抓包状态查询查询抓包数据在 Haruki 工具箱中的更新时间与有效性
/账号验证根据引导在游戏内完成账号归属权验证
/自定义个人信息背景上传自定义图片作为个人信息界面的底图

卡牌与服装查询​

查卡与卡牌列表​

/[区服]查卡 <角色名|卡牌ID|组合关键词>

多维度检索卡牌数据、立绘数值与技能倍率。

常用操作示例对应说明
/查卡 123查询 ID 为 123 的卡牌详细面板与数值
/查卡 25h列出 25点，Nightcord见 全员卡牌列表
/查卡 miku 4星 限定筛选初音未来的 4 星限定卡牌
/[区服]查卡面 <卡牌ID>获取指定卡牌的花前与花后高清原画
/[区服]卡牌列表 [筛选]生成卡牌缩略图矩阵列表
/[区服]卡牌一览查看所有卡牌的图鉴总览

查服装​

/[区服]查服装 <卡牌ID> [颜色位顺]

查询指定卡牌附带的演出服装与发型样式，支持切换 4 种异色形态预览。

常用操作示例对应说明
/查服装 114查看对应卡牌的默认服装样式
/查服装 114 2查看该服装的第 2 种染色版样式

音乐与乐曲谱面​

查曲与定数表​

/[区服]查曲 <歌曲ID|曲名|别名>

查询歌曲的基础信息、各难度等级、物量分布、谱师与所属活动。

常用操作示例对应说明
/查曲 112按歌曲 ID 查询详情
/查曲 虾通过常用歌曲别名查询
/[区服]难度排行查看各难度的官方定数与难度排行图
/[区服]查曲绘 <歌曲>获取歌曲官方曲绘封面大图
/[区服]查BPM <歌曲>查看歌曲初始 BPM 与变速走势
/[区服]查物量 <数值>查询物量等于该数值的歌曲

谱面预览与样式​

/[区服]谱面预览 <歌曲ID|曲名> [难度]

生成歌曲全曲谱面长图，直观预览轨道按键与走线细节（默认 MASTER 难度）。

常用操作示例对应说明
/谱面预览 112 expert预览指定歌曲 EXPERT 难度的谱面图
/谱面样式设置自定义谱面预览图的按键配色与背景透明度
/乐曲逮捕快速查询最近新实装的高难或话题乐曲

养成与打歌挖掘​

前置要求

本模块功能需先在 Haruki 工具箱中绑定账号并上传抓包数据。

每日挑战与打歌挖矿​

/[区服]每日挑战 / /[区服]挖矿

统计全曲库中本人尚未拿满的评级 S/Combo 水晶，计算剩余可挖水晶矿量。

常用操作示例对应说明
/每日挑战查询各角色每日挑战 Live 的达成等级与未领水晶
/挖矿统计本人尚未拿满奖励的歌曲与可挖矿量总数
/打歌进度生成 Clear / FC / AP 打歌成就汇总看板

角色加成与羁绊统计​

/[区服]角色加成 / /[区服]羁绊

查询角色间的牵绊等级、综合力加成百分比及区域道具升级情况。

常用操作示例对应说明
/角色加成查看各角色的综合力提升加成百分比
/羁绊查询本人角色间的牵绊等级与经验进度
/区域道具查看已升满与待升级的区域道具等级
/领队统计统计各角色担任领队（队长）的累计演出次数

活动与榜线 SK​

实时榜线与分数线​

/[区服]sk [排名|UID] / /[区服]sk线

实时查询当期活动的排名、点数、档位分数线与增长走势。

常用操作示例对应说明
/sk查询本人当期活动的即时排名与活动点数
/sk线查看当期活动全体重点档位（T100、T1000等）分数看板
/sk 1000查询 T1000 当前精确分数
/wl单榜 [角色名]查询 WorldLink (WL) 活动的分章节单人榜线
/sk查分综合查询当前分数在历史活动中的档位水平对比

时速、日速与查房监控​

/[区服]榜线时速 / /[区服]查房 <排名|UID>

统计榜线增长速度，查看目标玩家近期的打歌周回节奏与选曲情况。

常用操作示例对应说明
/榜线时速统计近 1 小时或指定时段的榜线增长速度（pt/h）
/榜线日速统计最近 24 小时的全服冲榜走势
/查房 1000查看目标排名玩家近期的打歌周回节奏与选曲
/玩家轨迹 <UID>绘制指定玩家在活动期间的分数成长折线图
/冲榜记录回溯个人在往期活动中的最终顺位与点数
/活动规划辅助制定目标排名所需的局数与火耗规划

智能组卡查询​

智能卡组推荐​

/[区服]活动组卡 / /[区服]挑战组卡

基于 Haruki 算力引擎与上传的卡牌资产，计算多种场景下的理论最优卡组。

常用操作示例对应说明
/活动组卡针对当期活动目标，计算最大化活动 PT 的配队方案
/挑战组卡针对每日挑战 Live 计算理论单人最高分队伍
/长草组卡非活动期纯分数最大化卡组
/控分组卡精确凑出指定加成与分数的配队方案
/烤森组卡针对 MySekai 探险产出最优配队

MySekai 烤森查询​

烤森资源与成就指引​

/[区服]ms / /[区服]烤森百景SK

针对 Project SEKAI 的 MySekai（烤森）玩法提供全方位的资源产出与地图指引。

常用操作示例对应说明
/ms查询烤森每日可采集资源、产出物明细与资源点大图
/烤森百景SK查询烤森成就与百景点数排行
/烤森大门升级查看大门各阶段升级所需素材与升级收益
/烤森收集清单统计个人的家具、图鉴与画布制作进度

综合娱乐与小工具​

综合实用小工具​

/[区服]虚拟Live / /[区服]角色生日

提供 Live 排期与角色纪念日查询。

常用操作示例对应说明
/虚拟Live查询最近即将演出的虚拟 Live 排期与观看报酬
/角色生日查询下一个即将过生日/纪念日的角色信息
/卡池查询查看当前正在开放或往期经典卡池详情
/查询歌曲别名 112查询歌曲已收录的常用别名
/添加歌曲别名 112 别名提交并推荐新的歌曲别名
