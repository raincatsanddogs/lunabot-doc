# 数学服务 (math)

提供安全且快速的数学表达式科学计算，以及全球最大的整数序列在线百科（OEIS）序列检索服务。

---

## 科学计算与表达式求值 {#eval}

### 计算表达式 {#eval-expr}
`/eval <表达式>`（别名：`/计算`）

基于 AST（抽象语法树）沙箱的安全计算引擎，支持基础四则运算、三角函数、指数对数及常见数学常量。算式遵循 Python 数学运算语法。

支持的内置函数与常数包括：常数 `pi`、`e`；算术函数 `sqrt`、`abs`、`round`、`exp`、`log` / `log10`；三角函数 `sin`、`cos`、`tan`、`asin`、`acos`、`atan` 等。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/eval 2**10 + 5 * 12` | 基础四则运算与幂指数运算 |
| `/eval sin(pi / 2) * sqrt(2)` | 复合三角函数与开根号计算 |
| `/计算 log(e**3) + abs(-42)` | 使用别名进行自然对数与绝对值求值 |

:::info 安全沙箱说明
求值引擎底层使用 Python `asteval` 库解析 AST，仅允许已注册的安全数学操作符与函数，杜绝任何系统调用与危险代码注入风险。
:::

## 整数数列检索 (OEIS) {#oeis}

### 查询整数序列 {#oeis-query}
`/oeis <序列片段>`

通过提供一段已知的整数片段，向 [OEIS](https://oeis.org)（整数数列线上大全）查询其序列名称、通项公式、数学背景及相关性质。参数建议提供 4 个以上整数以提高命中精度。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/oeis 1, 1, 2, 3, 5, 8, 13` | 查询斐波那契数列（Fibonacci numbers） |
| `/oeis 1, 2, 5, 14, 42, 132` | 查询卡特兰数（Catalan numbers） |
