# 水群与查重服务 (water)

提供群聊消息指纹计算与历史发言查重（俗称“查水过”或“水果”），支持排查火星图文、二手表情包以及群内多次重复搬运的内容。

---

## 手动水果查重 {#manual-check}

### 查询消息是否被水过 {#water-check}
`[引用回复] /water`（别名：`/水果`）

回复群聊中的任意一条消息，查询该内容是否在当前群历史记录中已被其他人发送过。Bot 将对比历史记录哈希库，若存在相同内容，将返回其首次出现时间、首位发送者以及累计被发送次数。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `[引用回复] /water` | 引用目标消息查询是否已被水过 |
| `[引用回复] /水果` | 使用别名进行查重检测 |

---

### 查询消息片段哈希值 {#hash-check}
`[引用回复] /hash`

回复群聊中的任意一条消息，计算并查看该消息中各媒体片段（纯文本、图片、表情等）的内部特征哈希。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `[引用回复] /hash` | 引用目标消息查看其媒体哈希指纹 |

---

## 自动水果检测配置 {#auto-water}

:::info 权限说明
本节指令仅限超级管理员 (SUPERUSER) 使用。
:::

### 配置群聊自动水果检测 {#autowater-config}
`/autowater <预设等级或媒体类型...>`

开启后，当群友在群内发送已被他人水过的图片、视频或文本时，Bot 会自动插话提示火星。支持指定预设等级或自由组合媒体类型（`text`, `image`, `stamp`, `video`, `forward`, `json`）。

预设等级对照：`off`（关闭）、`low`（转发+卡片）、`med`（视频+转发+卡片）、`high`（图片+视频+转发+卡片，推荐）、`all`（深度全量查重）。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/autowater high` | 开启高灵敏度媒体查重（推荐日常使用） |
| `/autowater text image` | 自由组合仅监听图片和纯文本 |
| `/autowater off` | 完全关闭当前群的自动水果检测 |

---

### 排除特定消息指纹 {#water-exclude}
`[引用回复] /water exclude`（别名：`/水果排除`）

将特定常发内容加入豁免白名单，不再触发自动水果提醒。通过引用回复目标消息发送，可将该条消息中包含的所有媒体片段哈希指纹排除在查重库之外。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `[引用回复] /water exclude` | 引用常发通知消息，将其媒体指纹排除在自动查重之外 |
| `[引用回复] /水果排除` | 使用中文别名排除所引用的消息指纹 |
