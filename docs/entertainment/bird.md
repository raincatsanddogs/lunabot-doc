# 鸟类查询 (bird)

提供鸟类物种科普信息、俗名对应及生态图片检索服务，数据来源于中文维基百科《中国鸟类列表》。

---

## 鸟类信息检索(暂不可用) {#search}

### 查询鸟类信息 {#bird-query}
`/bird <鸟类名称> [refresh]`（别名：`/鸟`、`/查鸟`）

通过鸟类的正式学名或日常俗称，快速获取鸟类的分类地位、外形特征与生活习性图片。数据来源于中文维基百科《中国鸟类列表》。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/bird 白鹭` | 查询白鹭的基础信息与科普图片 |
| `/鸟 戴胜` | 使用别名模糊查询鸟类信息 |
| `/bird 白鹭 refresh` | 强制清除本地图片缓存并重新拉取最新数据 |

:::info 数据来源与准确性说明
鸟类条目与图片数据动态抓取自中文维基百科《中国鸟类列表》，若遇到图片加载较慢或条目重名，可尝试输入更精确的学名或添加 `refresh` 刷新。
:::
