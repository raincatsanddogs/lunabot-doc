# 随机服务 (random)

提供群聊日常娱乐与纠结决策所需的随机数生成、选择器、列表乱序洗牌、随机抽取群友以及闽南传统中秋博饼小游戏。

---

## 随机抽取与决策 {#random-tools}

### 掷骰与随机数 {#roll}
`/roll [上限或区间]`（别名：`/随机数`、`/rand`）

在指定的闭区间范围内生成一个高随机性的整数结果。默认范围为 0 至 100；单参数为 1 至上限；双参数为指定下限至上限。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/roll` | 百分比检定，生成 0 至 100 之间的随机整数 |
| `/roll 6` | 6 面骰检定，生成 1 至 6 之间的随机整数 |
| `/roll 5 20` | 自定义区间，生成 5 至 20 之间的随机整数 |
| `/随机数 100` | 使用别名进行随机数投掷 |

---

### 随机选择 {#choose}
`/choose <选项1> <选项2> [其他选项...]`（别名：`/选择`、`/choice`）

纠结症福音，从输入的多个空格分隔候选项目中随机抽取 1 个。至少需提供 2 个候选项目。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/choose 麦当劳 肯德基 汉堡王 赛百味 炒饭` | 随机决定今天吃什么 |
| `/choose 石头 剪刀 布` | 随机出拳对决 |
| `/选择 选项A 选项B` | 使用别名进行二选一 |

---

### 乱序洗牌 {#shuffle}
`/shuffle <选项1> <选项2> [其他选项...]`（别名：`/洗牌`、`/打乱`）

将给定的一组选项或名单随机打乱顺序，重新生成排序。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/shuffle 玩家A 玩家B 玩家C 玩家D` | 为抽签或发言打乱玩家次序 |
| `/shuffle 1 2 3 4 5 6 7` | 对给定的数字列表进行乱序洗牌 |
| `/洗牌 苹果 香蕉 橙子 葡萄` | 使用别名打乱名单顺序 |

---

### 抽取随机群友 {#rolluser}
`/rolluser [数量]`（别名：`/随机群友`、`/randuser`）

从当前群聊的成员列表中随机挑选 1 位或多位幸运群友。数量参数缺省时默认为 1。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/rolluser` | 随机挑选 1 位当前群成员 |
| `/rolluser 3` | 随机挑选 3 位幸运群友 |
| `/随机群友` | 使用别名抽取群成员 |

## 闽南博饼游戏 {#bobing}

### 投掷博饼 {#bing}
`/bing`（别名：`/bobing`、`/博饼`、`/饼`）

中秋博饼是流行于闽南与台湾地区的民间中秋传统博彩游戏。使用六个骰子掷入瓷碗，按照出现的“四点（红四）”及点数组合判定科举功名奖项。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/bing` | 投掷一次博饼骰子并由 Bot 判定功名结果 |
| `/博饼` | 使用中文别名进行博饼 |

:::tip 判定规则摘要
游戏模拟掷 6 粒骰子：
- **秀才**：出现 1 个四点
- **举人**：出现 2 个四点
- **进士**：出现 4 个相同点数（非四点）
- **三红**：出现 3 个四点
- **榜眼（对堂）**：点数为 1, 2, 3, 4, 5, 6 各一个
- **状元**：4 个及以上四点，或 5 个相同点数，或 6 个点数相同（六杯红/遍地锦/插金花等高级状元）
:::

---

### 查看博饼完整规则 {#bing-rule}
`/bing rule`（别名：`/bobing rule`、`/博饼规则`）

获取中秋博饼完整的点数组合对照与科举功名规则图解说明。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/bing rule` | 查看完整的博饼奖项规则与点数图解 |
| `/博饼规则` | 使用别名调出博饼规则说明 |
