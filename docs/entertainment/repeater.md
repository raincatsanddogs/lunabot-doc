# 复读机服务 (repeater)

群聊自动 +1 复读服务。默认处于**关闭**状态，需由超级管理员在对应群内开启后生效。

---

## 核心机制说明 {#mechanism}

1. **+1 跟随复读**：
   - 当群内连续有不同群友发送完全相同的消息达到阈值（系统默认 3 人）时，Bot 将自动跟随复读 1 次。
   - 支持的消息类型包括：纯文本、QQ 原生表情、单张图片或表情包。
   - 具有防刷屏限制：每轮复读话题 Bot 仅跟随 1 次；群内一旦出现其他不同消息，自动重置复读状态。
2. **趣味概率打断**：
   - 当检测到群体复读达到阈值时，Bot 将根据配置概率（默认 10%）触发“打断复读”机制。
   - 打断时将随机从本地语料库发送打断台词，或从 [画廊服务](../media/gallery.md) 指定的图库抽取搞笑打断图。若画廊未启用则平滑降级为纯文本打断。
3. **安全过滤**：
   - 自动忽略包含 `@` 提及、回复引用或带有指令前缀的消息；Bot 自身发出的消息不计入连续统计。

---

## 复读机控制指令 {#admin}

### 开启复读服务 {#repeater-on}
🛠️ `/repeater on [群号]`（别名：`/repeat on`、`/复读 on`）

开启当前群聊或指定目标群聊的自动复读服务。指定群号可在私聊中远程管理。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/repeater on` | 在当前群开启自动复读服务 |
| `/repeater on 123456789` | 远程为群号 123456789 开启复读服务 |
| `/复读 on` | 使用中文别名开启复读 |

---

### 关闭复读服务 {#repeater-off}
🛠️ `/repeater off [群号]`（别名：`/repeat off`、`/复读 off`）

关闭当前群聊或指定目标群聊的自动复读服务。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/repeater off` | 在当前群关闭自动复读服务 |
| `/repeater off 123456789` | 远程为目标群关闭复读服务 |
| `/复读 off` | 使用中文别名关闭复读 |

---

### 查看复读状态 {#repeater-status}
`/repeater status [群号]`（别名：`/repeat status`、`/复读 status`）

查看当前群聊或指定目标群聊的自动复读机启用状态。全体群成员均可调用查询。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/repeater status` | 查看当前群的复读机启用状态与配置 |
| `/复读 status` | 使用别名查询复读机状态 |
