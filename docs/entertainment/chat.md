# AI 聊天服务 (chat)

LunaBot 基于大语言模型（LLM）提供智能聊天服务，支持多轮上下文对话、图文多模态识别、代码编写与沙箱执行、语音合成（TTS）、文本翻译，以及群内自动聊天记忆管理（UM）和全局表情包标注系统。

---

## AI 对话交互 {#ai-chat}

### 发起 AI 聊天 {#chat}
`/chat <提问内容>`（别名：`@Bot <提问内容>`）

与 Bot 进行智能对话。支持自然语言问答、代码辅助、文本润色与图片理解。直接回复 Bot 之前的回答消息即可自动携带上下文进行多轮对话；在提问消息中发送图片或回复图片可进行多模态识别。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/chat 你好，请做个自我介绍` | 使用斜杠指令发起对话 |
| `@Bot 怎么用 Python 写快速排序？` | 在群聊中艾特 Bot 提问 |
| `@Bot cleanmode 请介绍控制理论` | 干净模式，跳过预设人设系统提示词 |
| `@Bot 图片生成 星空下的橘猫` | 调用生图能力生成图片 |
| `@Bot 运行代码 计算第100个质数` | 提示模型编写 Python 代码并沙箱执行 |

:::tip 交互提示
当群内开启了 [自动聊天 (autochat)](#autochat-toggle) 时，为避免误触发，AI 聊天将只能通过 `/chat` 显式指令发起，不再响应普通 `@Bot`。
:::

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/translate 祝你今天过得愉快！` | 将中文文本翻译为英文 |

:::info 图片翻译说明

## 自动聊天记忆管理 (UM) {#autochat-um}

`/autochat um <参数>`（别名：`/um`）

负责管理当前群聊在自动闲聊过程中的长期记忆库，包含**事实（fact）**、**事件（event）**与**印象（impression）**。

<Tabs>
<TabItem value="query" label="记忆查询（全体成员）" default>

所有群成员均可自由查询群内已收录的有效记忆：

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/um` | 查询自己在当前群被记录的有效记忆条目 |
| `/um @群友` | 查询指定成员在当前群被记录的有效记忆 |
| `/um search 乌龙茶` | 在当前群记忆库中本地文本搜索关键词 |
| `/um list --page 2` | 分页浏览全群记忆列表（每页 10 条） |
| `/um show <ID>` | 查看指定记忆条目的主体、版本号与完整来源记录 |

</TabItem>
<TabItem value="admin" label="记忆维护（管理员/超管）">

:::info 权限说明
修改、审核与撤销操作仅限群管理员（🔧）或超级管理员（🛠️）使用。
:::

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/um add @群友 喜欢喝无糖乌龙茶` | 手工为指定群友新增一条事实记忆 |
| `/um edit <ID@版本> 喜欢喝大红袍` | 带版本号修订指定记忆的内容 |
| `/um delete <ID@版本>` | 撤销失效记忆并保留版本审计历史 |
| `/um history <ID>` | 审计该条记忆的历史版本及操作者变更链 |
| `/um list --status candidate` | 按状态过滤候选（如待审核重复、已撤销等） |
| `/um operation <操作ID>` | 查询后台异步写入结果 |

</TabItem>
</Tabs>

:::important 记忆版本与数据一致性机制
1. **版本锁防护**：编辑和撤销记忆时，必须准确携带列表中的 `ID@版本号`（例如 `0123456789abcdef01234567@2`）。若版本冲突，系统将返回最新版本号并拒绝覆盖，需核对后重新提交。
2. **人工修订防篡改**：由管理员手工录入或确认的记忆具有高置信度，旧的历史聊天记录分析不可自动覆写人工确认过的数据。
3. **软撤销与审计**：执行 `/um delete` 后条目将从召回知识库中排除，不再影响日常聊天生成，但历史版本与操作人留痕仍保留可查。
:::

## 自动聊天表情包标注 {#autochat-stickers}

:::info 权限说明
本节指令仅限管理员和超级管理员使用。
:::

LunaBot 具备智能表情包库系统。在群聊自动发言时，Bot 能根据当前语境、语气风格和情绪意图，自主选择发送纯文字、单张表情包或图文混排。

<Tabs>
<TabItem value="view" label="表情包查看（管理员/超管）" default>

群管理员与超管可查阅全局素材库的录入与标注详情：

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/autochat sticker list 柴犬` | 搜索素材列表并查看当前标注摘要（单次最多 30 条） |
| `/autochat sticker show <素材ID>` | 查看指定表情包的多模态标注详情与适用场景 |
| `/autochat sticker operation <操作ID>` | 查阅异步后台入库与多模态分析处理进度 |

</TabItem>
<TabItem value="manage" label="表情包管理（仅限超管）">

:::info 权限说明
素材录入、批量导入、字段人工修订与废弃停用仅限超级管理员 (SUPERUSER) 使用。
:::

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/autochat sticker add`（同消息附带图片） | 直接在同一条消息中附带 1 至 4 张图片录入全局表情库 |
| `/autochat sticker import 柴犬表情包 1-30` | 从画廊批量导入素材（单次最多 50 张） |
| `/autochat sticker edit <ID> avoid_contexts 严肃求助` | 人工订正禁忌对话语境标签 |
| `/autochat sticker delete <素材ID>` | 停用该表情素材 |

</TabItem>
</Tabs>

:::tip 表情包处理细节
- **异步处理与去重**：添加或导入后立即返回操作 ID，后台将调用配置的视觉多模态大模型进行自动特征提取。若素材哈希已存在，系统自动跳过重复标注以节省 API 额度。
- **发送冷却规则**：自动发言时同一表情包素材具备 60 秒冷却时间；单轮发言最多附带 2 个表情包。
:::

🛠️ `/autochat <on|off>`

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/autochat on` | 开启当前群聊的自主主动闲聊 |
| `/autochat off` | 关闭当前群聊的主动闲聊功能 |

### autochat 特性 {#autochat-feature}

#### 触发方式 {#trigger-modes}

Bot 依据群内消息的语境与互动状态，通过以下四种方式综合计算最终触发概率：

1. **群内闲聊触发**：
   普通群成员之间日常聊天时，默认有 0.8% 的基础概率主动插话。
2. **关键词加成触发**：
   当群内消息中出现配置的关键词时，Bot 会加算关键词加成概率。若存在权重 $\le -1.0$ 的强阻断词，则完全不回复。
3. **直接@ / 回复触发**：
   当群内有人 `@Bot` 或直接引用回复 Bot 的发言时，基准概率为 100%（未被强阻断时必定触发）。
4. **互动保持**：
   Bot 自动回复后，会将**先前触发 Bot 回复的用户**加入关注列表（默认保留 120 秒），在此期间该用户的后续发言将有 85% 的跟进回复基础概率。

- **分段发送与频次保护**：Bot 依据群内活跃度与语境按需插话，支持多段分步发送（单轮最多 10 条，间隔不少于 1 秒）。
- **联网增强**：Bot 在遇到时效性问题时可自主检索互联网最新事实后再组织语言回答。
