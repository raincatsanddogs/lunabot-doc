# LunaBot 帮助文档

欢迎查阅 **LunaBot** 的指令文档与使用手册！

LunaBot 是一款基于 [NoneBot2](https://nonebot.dev/) 框架开发的多功能个人 / 群聊机器人。项目集成了丰富的主题服务，包括 **Project SEKAI** 综合查询与娱乐系统、Minecraft 服务器联动、AI 对话交互、图片处理与搜图工具，以及细致完备的群聊管理运维能力。原代码仓库为 [StarMoe-org/lunabot](https://github.com/StarMoe-org/lunabot)，bot主对其进行了fork与部分修改。

---

## 核心特性与模块概览 {#features}

文档根据功能领域划分为 5 大专区，涵盖 20+ 个独立功能服务：

| 专区分类 | 包含服务 | 核心功能简介 |
| :--- | :--- | :--- |
| **[基础通用](/docs/general)** | 基础指令、状态检测、广播、定时提醒 | Bot 基础管理、开关控制、自检与定时任务调度 |
| **[游戏专区](/docs/games/haruki)** | Haruki服务 (PJSK综合查询)、世界计划 (公开查询与娱乐)、Minecraft | PJSK 跨区服数据、查卡查曲、榜线追踪、MySekai、娱乐小游戏与 MC 服务器互联 |
| **[多媒体与图像](/docs/media/imgtool)** | 图片处理、以图搜图、画廊系统、贴表情 | 多种图像处理工具、多引擎搜图、群相册管理与表情包制作 |
| **[智能与娱乐](/docs/entertainment/chat)** | AI 聊天、鸟类科普、代码运行、数学计算、随机、复读机、水群勋章 | LLM 大模型拟人对话、沙箱安全运行代码、趣味群娱乐互动 |
| **[管理运维](/docs/management/record)** | 消息记录、发言统计、加退群通知 | 群聊发言数据存档、每日消息统计与进出群事件广播 |
