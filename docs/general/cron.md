# 定时任务服务 (cron)

提供灵活直观的定时提醒服务。支持直接使用日常自然语言（如“每天早上8点”、“本周五下午3点”）通过 LLM 语义分析自动解析定时表达式与提醒内容，到达触发时间后在群内自动 @ 订阅者。

---

## 创建与维护提醒 {#create-and-manage}

### 添加定时提醒 {#add}
`/cron add <自然语言描述>`（别名：`/cron`、`/添加提醒`）

通过日常说话的方式创建定时提醒，系统会自动提取周期、时间点与提醒内容，并默认将创建者设为第一订阅人。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/cron add 每天早上1点提醒大家起床` | 创建每日周期性定时提醒 |
| `/cron add 今天下午25点提醒我睡觉` | 创建单次定时提醒 |
| `/添加提醒 每周四中午11点提醒疯狂星期四` | 使用中文别名创建每周周期任务 |

---

### 查询定时任务列表 {#list}
`/cron list`（别名：`/提醒列表`）

列出当前群内正在运行的所有定时任务及其任务 ID、触发周期与提醒内容。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/cron list` | 查看当前群内全部定时提醒任务清单 |
| `/提醒列表` | 使用中文别名查看任务列表 |

---

### 修改与维护定时任务 {#edit}
`/cron edit <任务ID> <新时间与内容>`

修改已有提醒的任务规则（仅任务创建者或超级管理员可用）。支持临时静音与恢复。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/cron edit 1 改为每天上午9点起床` | 调整指定 ID 任务的触发时间与内容 |
| `/cron mute 1` | 临时静音暂停指定任务的触发 |
| `/cron unmute 1` | 恢复指定任务的定时调度 |

---

### 删除定时提醒 {#del}
`/cron del <任务ID>`（别名：`/删除提醒`）

删除指定任务 ID 的定时提醒（仅创建者或超级管理员可用）。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/cron del 1` | 删除 ID 为 1 的定时提醒任务 |
| `/删除提醒 2` | 使用中文别名删除指定任务 |

---

## 订阅与接收者管理 {#subscribers}

### 任务订阅与接收者管理 {#manage-subscribers}
`/cron sub <任务ID> [@成员]` / `/cron unsub <任务ID>`

定时提醒触发时，系统会自动在提醒消息后附带并 @ 全体已订阅的群成员。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/cron sub 1` | 为自己订阅该任务，到点自动被 @ 提醒 |
| `/cron unsub 1` | 取消自己对该任务的订阅 |
| `/cron sub 1 @群友` | 为指定群友添加订阅（仅创建者或超管） |
| `/cron sublist 1` | 查看特定任务当前的所有订阅者名单 |
| `/cron mysub` | 列出自己在当前群所订阅的全部定时提醒任务 |

## 群聊提醒清理 {#admin}

:::info 权限说明
本节指令仅限超级管理员 (SUPERUSER) 使用。
:::

### 批量清理与重置提醒 {#admin-cleanup}
🛠️ `/cron muteall` / 🛠️ `/cron clear`（别名：`/关闭所有提醒`、`/清空提醒`）

紧急批量暂停或注销当前群聊的定时提醒服务。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/cron muteall` | 紧急一键暂停当前群的所有定时任务触发 |
| `/cron clear` | 彻底清空并注销当前群聊的所有定时提醒数据 |
