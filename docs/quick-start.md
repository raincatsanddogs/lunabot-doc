## 指令调用格式 {#syntax}

### 1. 指令前缀与自定义配置 {#prefix}

在群聊中，指令前缀斜杠 `/` 可能会与群内其他机器人产生前缀冲突。

为此，Bot 端在接收指令、生成帮助索引、渲染详情长图及纯文本引导时，会自动将 `/` 转换为实际生效的前缀（例如 `/help`、`/alive`、`/查卡 200`）（帮助文档的原有指令前缀均为 `/`）。

你可以在下方交互模拟器中体验前缀转换效果：

<CommandPrefixSwitcher />

:::tip 群聊调用提示
在群聊环境下，部分管理类或开关类指令可能需要 `@Bot` 配合使用（例如 `@Bot /enable`），以防止与其他机器人的前缀冲突或误触。
:::

### 2. 获取帮助 {#help}
LunaBot 内置了多级帮助机制：

- `/help`：获取当前所有可用服务的列表索引。
- `/help <服务名>`：查看指定服务的分页指令清单（例如 `/help sekai`、`/help general 2`）。
- `/help <服务名> <指令名>`：查看具体指令的详细用法、参数说明与示例（例如 `/help sekai 查卡`）。
- `/<指令名> help`：在部分指令后直接追加 `help` 也可以单独获取该指令的帮助。

## 权限等级说明 {#permissions}

在各指令帮助文档中，你会看到以下特殊图标标注：

| 标识 | 权限要求 | 说明 |
| :---: | :--- | :--- |
| *(无标识)* | **普通用户** | 任何群成员或私聊用户均可正常调用 |
| 🔧 | **群管理员 / 维护者** | 需拥有群管理员、群主或维护者身份 |
| 🛠️ | **超级管理员 (SUPERUSER)** | 仅限在配置文件中登记的 Bot 拥有者 / 超级管理账号使用 |

:::caution 注意
标记为 🛠️ 的指令通常涉及群聊开启/关闭、系统底层服务开关、黑名单管理、代码执行与数据清理等高危敏感操作，普通成员执行这些指令将不会产生任何响应。
:::

## 常用群聊控制指令 {#group-quickstart}

在新群首次引入 LunaBot 时，通常需要完成以下配置：

```text
# 1. 开启当前群聊响应 (默认为关闭状态)
@Bot /enable

# 2. 查看当前群聊启用的服务列表
/group status

# 3. 按需开启或关闭特定服务 (例如开启 AI 聊天服务)
/chat on
/chat off
```

更多通用指令与管理操作，请查阅 **[基础指令 (general)](/docs/general)** 文档。
