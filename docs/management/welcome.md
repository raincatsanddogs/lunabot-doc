# 加退群通知 (welcome)

提供新成员加入群聊时的自动问候与规则引导服务，支持灵活的动态变量占位符。

:::info 功能状态
当前支持**新成员进群提醒**；退群及移出成员提醒暂不可用。
:::

---

## 新成员进群欢迎 {#welcome-message}

### 设置入群欢迎词 {#welcome-info}
🛠️ `/welcome info [欢迎词内容]`（别名：`/欢迎信息`、`/入群信息`）

配置当新成员通过验证加入当前群聊时，Bot 自动在群内发送的欢迎问候语（限超级管理员）。若不带任何参数，则直接清除并停用欢迎消息。

欢迎词模板中可嵌入以下动态占位符：
- `@`：实际触发一次对该新进群成员的 `@` 提及提醒。
- `{user}`：纯文本替换为该新成员的个人昵称（不产生艾特提示）。
- `{user_id}`：替换为该新成员的实际 QQ 号码。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/欢迎信息` | 清除当前群的欢迎配置（停止进群提醒） |
| `/欢迎信息 欢迎新伙伴加入我们群！` | 设置纯文本欢迎问候 |
| `/欢迎信息 欢迎 @ 入群！你的昵称是 {user} ({user_id})` | 组合使用动态占位符与 @ 提示 |
| `/welcome info 欢迎加入！请查阅群公告` | 使用英文指令配置欢迎词 |
