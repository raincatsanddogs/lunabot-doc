# 群消息统计 (sta)

基于 `record` 服务持久化的群聊消息，对群内发言活跃度、发言时段分布、高频词汇与群友画像进行多维度可视化分析与图表渲染。

---

## 统计图表生成 {#charts}

### 发送每日群消息统计图 {#sta-day}
`/sta day [日期|相对天数]`

生成并发送单日群聊消息统计长图（包含发言榜饼图、高频关键词词云与 24 小时活跃分布条形图）。参数缺省时统计今日 0 点至今的发言概况。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/sta day` | 统计今日凌晨 0 点至今的群发言概览长图 |
| `/sta day 2024-05-01` | 统计指定历史日期的全天发言（格式 `YYYY-MM-DD`） |
| `/sta day -7` | 统计 7 天前那一整天的群聊历史数据 |

---

### 发送跨周期消息汇总图 {#sta-sum}
`/sta sum <天数或开始日期> [结束日期]`

统计较长时间跨度内的群聊消息总览长图，内容结构与单日统计图保持一致。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/sta sum 25` | 统计最近 25 天至今的消息汇总长图 |
| `/sta sum 2525-01-27` | 统计自指定日期至今的全群消息数据 |
| `/sta sum 2525-02-10 2525-04-30` | 统计指定闭合时间区间内的群聊数据 |

---

### 发送活跃时段分布图 {#sta-time}
`/sta time <天数> [@成员]`

生成全群或单个成员在最近周期内的 24 小时作息与活跃时段热力分布图。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/sta time 7` | 查看全群最近 7 天的 24 小时发言时段分布 |
| `/sta time 7 @群友` | 查看指定群友最近 7 天的在线活跃时段分布 |

---

### 发送关键词频度分析图 {#sta-word}
`/sta word <词汇列表> <天数>`

追踪群聊在指定天数内特定词汇的热度变化与走势折线图。多个词汇之间使用英文逗号分隔。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/sta word 疯狂星期四,v我50 7` | 对比两个关键词在最近 7 天内的讨论频度走势 |
| `/sta word 吃什么 30` | 查看单个词汇在最近 30 天的热度变化 |

## 定时推送与词库维护 {#admin}

:::info 权限说明
本节指令涉及定时调度与全局分词词库修改，仅限超级管理员 (SUPERUSER) 使用。
:::

### 每日统计定时自动发送 {#sta-notify}
🛠️ `/sta notify <on|off>`

配置 Bot 在每天固定时间（通常为夜间 23:59 或次日凌晨）自动向本群推送昨日群消息统计图。同时支持紧急取消当天的自动播报。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/sta notify on` | 开启本群每日统计自动播报 |
| `/sta notify off` | 关闭本群每日统计自动播报 |
| `/sta cancel today` | 紧急取消当天的自动播报任务（仅单次生效） |

---

### 分词词典管理 {#sta-dict}
🛠️ `/sta add <词汇...>` / 🛠️ `/sta ban <词汇...>`

维护中文分词词库。将专有名词加入用户词典以防止被分词器切碎；将高频无意义助词加入停用词表，生成词云时自动过滤屏蔽。

| 常用操作示例 | 对应说明 |
| :--- | :--- |
| `/sta add 宵崎奏 朝比奈真冬 疯狂星期四` | 将专有名词加入分词词库以正确识别 |
| `/sta ban 确实 哈哈 真的` | 将无意义水群高频词加入停用词表 |
